# Common-password deny list (work package A02; docs/reference/limits-and-caps.md section B).
#
# One entry per line, case-insensitive; blank lines and lines starting with "#" are ignored.
# app/auth/passwords.py compares the submitted password against every entry, and also against
# the password with leading and trailing non-letters removed and with the obvious digit-for-letter
# substitutions undone, so "password" here also rejects "Password1234" and "p4ssword!!".
#
# Scope of this file. The policy the plan freezes is "minimum 12 characters, top-10k deny list".
# The 12-character minimum already rejects the great majority of any published top-10k list, so
# what has to be written down is (a) the long entries that survive it and (b) the short base words
# that the variant rules turn into long guesses. That is what this file holds; it is a curated
# subset, not a copy of a published list, because a build that downloads a word list is a build
# that can be poisoned and cannot be reproduced offline.
#
# The full list is still available to any deployment that wants it: point
# BB_PASSWORD_DENYLIST_FILE at a top-10k file and it is used *in addition* to this one
# (docs/security/authn-authz.md). Adding an entry here is a normal change; removing one needs a
# reason, because every line is a password somebody has already guessed.
#
